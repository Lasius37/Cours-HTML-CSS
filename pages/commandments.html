    1. Construire le HTML en premier tu feras

    Le contenu est toujours la priorité du site.

    2. Une structure claire tu définiras

    Utiliser les balises de structure (<header>, <nav>, <main>, <section>, <footer>) au lieu de la balise universelle <div>.

    3. Des commentaires tu écriras

    Ils servent de repère dans le code facilitent les corrections d’erreurs.

    4. Ton code tu indenteras

    La lisibilité du code est essentielle pour comprendre et corriger les erreurs.

    5. Des classes tu utiliseras

    Elles évitent les répétitions inutiles dans le code CSS.

    6. Le CSS tu soigneras

    Choisir avec soin les espacements, les polices et la mise en page améliore l’expérience utilisateur.

    7. Les couleurs tu limiteras

    En plus du noir et du blanc (ou des couleurs proches), on utilise généralement 2 couleurs principales, exceptionnellement 3 ; attention à ne pas en abuser.

    8. Tes fichiers tu rangeras

    Le rangement clair limite les erreurs et facilite la maintenance du projet.

    9. L'orthographe tu corrigeras

    Un site comportant des fautes d’orthographe perd immédiatement en crédibilité.

    10. Dans la difficulté tu presévéreras

    Les développeurs professionnels peuvent passer plusieurs heures à chercher une erreur minuscule. La patience fait partie du métier.
